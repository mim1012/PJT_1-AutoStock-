## 종목 설정 파일 형식

### us_stocks_config.json
```json
{
    "filter_stocks": {
        "NVDA": true,    // 필터 종목 (시장 방향 판단)
        "AMZN": true,
        "MSFT": true
    },
    "watch_list": [      // 매매 대상 종목
        "SOUN", "RGTI", "SMCI"
    ]
}
```

### kr_stocks_config.json
```json
{
    "filter_stocks": {
        "005930": true,  // 삼성전자
        "000660": true,  // SK하이닉스
        "035420": true   // NAVER
    },
    "watch_list": [
        "035720",        // 카카오
        "247540"         // 에코프로비엠
    ]
}
```

## 환경 변수 (.env)

```env
# API 인증
KIS_APP_KEY=your_app_key
KIS_APP_SECRET=your_app_secret
KIS_ACCOUNT_NUMBER=12345678-01

# 거래 모드
USE_PAPER_TRADING=True    # True=모의, False=실전

# 로그 레벨 (선택)
LOG_LEVEL=INFO            # DEBUG, INFO, WARNING, ERROR
```

## 자주 변경하는 설정

### 목표 수익률 변경
```python
# config.py:36
PROFIT_THRESHOLD = 0.03  # 3%로 변경
```

### 손절 기준 변경
```python
# config.py:37
STOP_LOSS_THRESHOLD = -0.10  # -10%로 변경
```

### 매매 주기 변경
```python
# config.py:42-43
SELL_INTERVAL_MINUTES = 15  # 15분마다 매도 체크
BUY_INTERVAL_MINUTES = 30   # 30분마다 매수 체크
```

### 모의투자 ↔ 실전투자
```env
# .env 파일
USE_PAPER_TRADING=False  # 실전투자로 전환
```
