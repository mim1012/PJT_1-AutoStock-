## 1. 시스템 개요

### 1.1 주요 기능
- **듀얼 마켓 지원**: 미국(NASDAQ, NYSE, AMEX) + 한국(KOSPI, KOSDAQ) 동시 거래
- **자동 시장 전환**: 현재 시간 기준 활성 시장만 모니터링
- **토큰 자동 관리**: OAuth2 토큰 자동 발급/갱신 (24시간 제한 준수)
- **손절매 자동화**: 설정 손실률 도달 시 자동 매도 + 재매수 금지
- **모의투자 지원**: 실전 투자 전 안전한 테스트

### 1.2 시스템 요구사항
| 항목 | 요구사항 |
|------|----------|
| OS | Windows 10 이상 |
| Python | 3.8 이상 (3.11 권장) |
| 인터넷 | 안정적인 연결 필수 |
| API | 한국투자증권 OpenAPI 인증 정보 |

### 1.3 거래 시간
| 시장 | 거래 시간 | 시간대 |
|------|----------|--------|
| 미국 | 09:30 ~ 16:00 | ET (동부시간) |
| 한국 | 09:00 ~ 15:30 | KST (한국시간) |

> **참고**: 미국 시장은 서머타임 자동 적용됨 (pytz 라이브러리)

## 2. 설치 및 초기 설정

### 2.1 자동 설치 (권장)
```batch
setup.bat
```
실행하면 다음이 자동 수행됨:
- Python 패키지 설치
- `.env` 파일 생성 (템플릿에서 복사)
- 메모장으로 `.env` 파일 열기

### 2.2 수동 설치
```bash
# 1. 패키지 설치
pip install -r requirements.txt
pip install mojito2

# 2. 환경 설정 파일 생성
copy .env.example .env

# 3. .env 파일 편집
notepad .env
```

### 2.3 API 인증 정보 설정

#### API 키 발급 절차
1. [한국투자증권 API 포털](https://apiportal.koreainvestment.com) 접속
2. 회원가입 및 로그인
3. API 신청 → APP KEY, APP SECRET 발급
4. 계좌번호 확인 (형식: `12345678-01`)

#### .env 파일 설정
```env
KIS_APP_KEY=발급받은_APP_KEY
KIS_APP_SECRET=발급받은_APP_SECRET
KIS_ACCOUNT_NUMBER=12345678-01
USE_PAPER_TRADING=True
```

| 변수 | 설명 | 예시 |
|------|------|------|
| `KIS_APP_KEY` | API 앱 키 | PSxxx... |
| `KIS_APP_SECRET` | API 시크릿 | xxx... |
| `KIS_ACCOUNT_NUMBER` | 계좌번호 (하이픈 필수) | 12345678-01 |
| `USE_PAPER_TRADING` | True=모의투자, False=실전 | True |

## 4. 종목 설정

### 4.1 미국 주식 설정 (`us_stocks_config.json`)

```json
{
    "filter_stocks": {
        "NVDA": true,
        "AMZN": true,
        "MSFT": true
    },
    "watch_list": ["SOUN", "RGTI", "SMCI", "QUBT"]
}
```

| 항목 | 설명 |
|------|------|
| `filter_stocks` | 시장 방향 판단용 기준 종목 (대형주 권장) |
| `watch_list` | 실제 매매 대상 종목 |

**필터 동작**: `filter_stocks`의 모든 종목이 상승 중일 때만 매수 (AND 조건)

### 4.2 한국 주식 설정 (`kr_stocks_config.json`)

```json
{
    "filter_stocks": {
        "005930": true,
        "000660": true,
        "035420": true
    },
    "watch_list": ["035720", "247540", "293490"]
}
```

| 종목코드 | 종목명 |
|----------|--------|
| 005930 | 삼성전자 |
| 000660 | SK하이닉스 |
| 035420 | NAVER |
| 035720 | 카카오 |

> **참고**: 한국 주식은 6자리 종목코드 사용

### 4.3 거래소 자동 감지 (미국)

미국 주식은 거래소를 자동으로 감지합니다:
1. yfinance로 거래소 확인 시도
2. 실패 시 NASDAQ → NYSE 순차 시도
3. 결과를 캐시에 저장하여 재사용

지원 거래소:
- **NAS**: NASDAQ (나스닥)
- **NYS**: NYSE (뉴욕증권거래소)
- **AMS**: AMEX (아메리칸증권거래소)

## 5. 매매 전략 이해

### 5.1 매수 전략

**실행 주기**: 60분마다 (`BUY_INTERVAL_MINUTES`)

**매수 조건**:
1. 장 시간 내
2. 필터 조건 충족 (filter_stocks 전체 상승)
3. watch_list 중 하락률 상위 3개 종목 선택
4. 손절 블랙리스트에 없는 종목
5. 이전 매도가보다 낮은 가격

**포지션 크기**: 예수금 기준 자동 계산 (최대 100주/종목)

### 5.2 매도 전략

**실행 주기**: 30분마다 (`SELL_INTERVAL_MINUTES`)

| 시장 | 익절 조건 | 손절 조건 |
|------|----------|----------|
| 미국 | +5% 이상 | 없음 (수동) |
| 한국 | +5% 이상 | -15% 이하 |

### 5.3 손절매 시스템 (한국 전용)

**동작**:
1. 보유 종목이 -15% 손실 도달
2. 자동 시장가 매도
3. 블랙리스트 등록 (50일간 재매수 금지)

**관련 파일**:
- `stop_loss_tracker.py` - 블랙리스트 관리
- `kr_stop_loss_blacklist.json` - 블랙리스트 데이터

## 6. 토큰 관리

### 6.1 토큰 파일 구조

| 파일 | 용도 |
|------|------|
| `us_api_token.json` | 미국 주식 API 토큰 |
| `kr_api_token.json` | 한국 주식 API 토큰 |
| `us_token_issued_at.dat` | US 토큰 발급 시각 |
| `kr_token_issued_at.dat` | KR 토큰 발급 시각 |
| `us_krs_token.dat` | mojito2 토큰 (US) |

### 6.2 24시간 제한

**중요**: 한국투자증권 API는 **하루에 1번만 토큰 발급** 가능

- 토큰 유효기간: 24시간
- 자동 갱신: 잔여 5시간 미만 시 시도
- 재발급 대기: 24시간 경과 후 가능

### 6.3 토큰 수동 관리

```bash
# 미국 토큰 발급/갱신
python -m us.token_manager get

# 한국 토큰 발급/갱신
python -m kr.token_manager get
```

### 6.4 토큰 문제 해결

| 증상 | 원인 | 해결 |
|------|------|------|
| "토큰 발급 불가" | 24시간 미경과 | 다음 날까지 대기 |
| "토큰 만료" | 24시간 초과 | 자동 갱신 대기 또는 수동 발급 |
| "인증 실패" | API 키 오류 | .env 파일 확인 |

> **주의**: 토큰 파일(`*_api_token.json`)을 임의로 삭제하지 마세요!

## 7. 로그 및 거래 기록

### 7.1 실행 로그

**파일**: `trading.log`

**설정** (config.py):
- 크기 제한: 10MB
- 백업 개수: 5개
- 로그 레벨: INFO (환경변수 `LOG_LEVEL`로 변경 가능)

**실시간 확인** (PowerShell):
```powershell
Get-Content trading.log -Wait -Tail 50
```

### 7.2 거래 기록 (CSV)

**파일 위치**: `transaction_logs/`

| 파일명 패턴 | 내용 |
|------------|------|
| `trading_log_YYYYMMDD.csv` | 미국 주식 거래 |
| `kr_trading_log_YYYYMMDD.csv` | 한국 주식 거래 |

**CSV 필드**:
```
timestamp, action, symbol, quantity, price, profit_loss, profit_rate, balance, notes
```

**Excel에서 열기**:
1. Excel 실행
2. 파일 → 열기 → CSV 선택
3. 인코딩: UTF-8 (BOM) 자동 인식

## 8. 문제 해결

### 8.1 설치 오류

| 오류 | 해결 방법 |
|------|----------|
| `pip not found` | Python 재설치 (PATH 체크) |
| `mojito2 설치 실패` | `pip install mojito2 --upgrade` |
| `ModuleNotFoundError` | `pip install -r requirements.txt` |

### 8.2 실행 오류

| 오류 | 원인 | 해결 |
|------|------|------|
| "KIS_APP_KEY가 설정되지 않았습니다" | .env 파일 없음 | .env 파일 생성 |
| "계좌번호 형식 오류" | 하이픈 누락 | `12345678-01` 형식 확인 |
| "토큰 획득 실패" | API 키 오류 | .env 값 확인 |
| "거래소 감지 실패" | 종목코드 오류 | 종목코드 확인 |

### 8.3 거래 오류

| 오류 | 원인 | 해결 |
|------|------|------|
| "잔고 부족" | 예수금 부족 | 입금 또는 포지션 축소 |
| "주문 거부" | 장외 시간 | 거래 시간 확인 |
| "수량 초과" | 보유 수량 부족 | 수량 확인 |

### 8.4 로그 확인 방법

```powershell
# 최근 오류만 확인
Select-String -Path trading.log -Pattern "ERROR" | Select-Object -Last 20

# 특정 종목 거래 확인
Select-String -Path trading.log -Pattern "NVDA"
```

## 9. 설정 변경 가이드

### 9.1 주요 설정 위치

| 설정 | 파일 | 변수 |
|------|------|------|
| 목표 수익률 | `config.py:36` | `PROFIT_THRESHOLD = 0.05` |
| 손절 기준 | `config.py:37` | `STOP_LOSS_THRESHOLD = -0.15` |
| 매도 주기 | `config.py:42` | `SELL_INTERVAL_MINUTES = 30` |
| 매수 주기 | `config.py:43` | `BUY_INTERVAL_MINUTES = 60` |
| 재매수 금지 기간 | `us/config.py:39` | `STOP_LOSS_COOLDOWN_DAYS = 50` |

| 한국 장 시간 | `kr/config.py:32-33` | `TRADING_START/END_TIME` |


```python

```

