## 5. 배포 명령어

### Windows PowerShell에서 실행

```powershell
# 1. 제거 대상 파일 삭제
Remove-Item -Path "AutoTrading_Release\.env" -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\*_api_token.json" -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\*_token_issued_at.dat" -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\*_krs_token.dat" -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\*.log" -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\transaction_logs\*.csv" -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\__pycache__" -Recurse -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\common\__pycache__" -Recurse -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\us\__pycache__" -Recurse -ErrorAction SilentlyContinue
Remove-Item -Path "AutoTrading_Release\kr\__pycache__" -Recurse -ErrorAction SilentlyContinue

# 2. ZIP 파일 생성
Compress-Archive -Path "AutoTrading_Release\*" -DestinationPath "AutoTrading_v4.7_Release.zip" -Force

# 3. 확인
Get-ChildItem "AutoTrading_v4.7_Release.zip"
```

### 또는 수동으로

1. AutoTrading_Release 폴더 복사
2. 위 "배포 전 제거 항목" 수동 삭제
3. ZIP으로 압축
