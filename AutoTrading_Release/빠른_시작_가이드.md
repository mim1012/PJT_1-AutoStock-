# 한국투자증권 자동매매 시스템 v4.7 - 빠른 시작 가이드

## 5분 안에 시작하기

### 1단계: 설치 (1분)
```
setup.bat 더블클릭
```
- Python 패키지 자동 설치
- .env 파일 자동 생성

### 2단계: API 키 입력 (2분)

setup.bat 실행 시 자동으로 메모장이 열립니다.

다음 정보를 입력하세요:
```
KIS_APP_KEY=발급받은_APP_KEY
KIS_APP_SECRET=발급받은_APP_SECRET
KIS_ACCOUNT_NUMBER=12345678-01
USE_PAPER_TRADING=True
```

> **API 키 발급**: https://apiportal.koreainvestment.com

### 3단계: 종목 설정 (1분)

#### 미국 주식 (`us_stocks_config.json`)
```json
{
    "filter_stocks": {"NVDA": true, "AMZN": true},
    "watch_list": ["SOUN", "RGTI", "SMCI"]
}
```

#### 한국 주식 (`kr_stocks_config.json`)
```json
{
    "filter_stocks": {"005930": true, "000660": true},
    "watch_list": ["035720", "247540"]
}
```

### 4단계: 실행 (1분)

| 실행 파일 | 설명 |
|----------|------|
| `start_auto.bat` | **권장** - 자동 시장 전환 |
| `start.bat` | 미국 주식만 |
