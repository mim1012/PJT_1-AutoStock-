# 단테식 매매 파이프라인 — 검색기 포착 → 타점 → 진입 순서

> 질문: "검색기로 포착 → 타점 잡기, 어느 순서로?"
> 답: 단테는 **발굴(일봉·마감후)과 타점(분봉·장중)을 분리한 2단계 깔때기**로 운영한다.
> 근거: 유튜브 영상 08·14·16·18 (RESEARCH/dante_youtube_screener_conditions.md).
> 단테 원문 비유: *"투망을 던져 200마리를 가둔다(발굴). 그중 잡고기를 골라낸다(타점)."*

---

## 핵심 원칙 — 하나의 검색기로 둘 다 하지 않는다

| | 1단계: 발굴(포착) | 2단계: 타점 |
|---|---|---|
| **목적** | "살 만한 종목군" 추리기 | "지금 사는 자리" 포착 |
| **봉** | 일봉 | 분봉(5분봉) |
| **시점** | **장 마감 후**(확정 종가) | **장중 실시간** |
| **실시간성** | 불필요 | 필요(좁은 워치리스트만) |
| **결과 규모** | 수천 → 수십 종목 | 수십 → 매수 1~3 |
| **우리 구현** | `scripts/eod_scan.py` ✅ | `should_buy` 일부 + TODO |

→ 이 분리가 그동안 고민한 "HTS 실시간" 문제를 푼다: **발굴은 실시간 필요 없고(마감 후 일봉), 타점만 장중 실시간**인데 대상이 워치리스트 수십 종목뿐이라 KIS 단독(웹소켓/짧은 폴링)으로 충분.

---

## 운영 순서 (Stage 0 → 4)

### Stage 0 — 발굴 (장 마감 후, 일봉) ✅ 구현됨
- **시점**: KR 15:40 KST / US 16:10 ET (스케줄러 자동)
- **실행**: `scripts/eod_scan.py` → `RESEARCH/eod/eod_{market}_{날짜}.md`
- **검색기**:
  - breakout 세력봉 (`screen`)
  - 단테 역배열 스윙 B-1 (`screen_dante_reversal`) + 역배열 워치리스트
- **산출물**: 내일 볼 **후보군 + 워치리스트** (확정 종가라 안 바뀜)

### Stage 1 — 개장 전 정리 (아침)
- 워치리스트 로드 + 갭/뉴스 1차 필터 (단테: 뉴스로 이미 갭 뜬 건 제외, 재료 미노출 갭만)
- (선택) TradingAgents AI 사전분석 — 이미 08:45 KST 자동 실행됨(`USE_TA_FILTER`)
- → "오늘 감시할 N종목" 확정

### Stage 2 — 타점 포착 (장중, 분봉 실시간) ⚠️ 부분구현/TODO
워치리스트 종목**만** 대상으로 진입 자리 감시 (단테 2차 타점식):
- 5분봉 **일목 기준선 1.5~3% 근접** (눌림 도달)
- **볼린저밴드** 근접
- **5일선 회복/근접** (오도리 자리)
- **체결강도 ≥110**, 매도/매수 **호가잔량비 ≥150%** (실시간 호가 — KIS 웹소켓 필요)
- → 조건 충족 순간이 "타점"

### Stage 3 — 진입 판정 (`should_buy` 8관문) ✅ 구현됨
블랙리스트 → 직전매도가 → 킬스위치 → 시간대 → 등락률 → 검색기 → 엔진 → TA → **주문**

### Stage 4 — 청산 (`should_sell`) ✅ 구현됨
손절(단테: **돌파 기준봉 저점/5일선 이탈**) > 익절 > 트레일링
